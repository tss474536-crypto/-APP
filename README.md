# 诗诗课表

一个真正的原生 Android 应用，不是网页套壳。使用 Kotlin + Jetpack Compose 编写，第一版完全本地运行，不需要服务器。

## 已完成的功能

- 今天课表、本周课表、同一时段冲突课程叠放
- 课程新增、修改、删除，支持周次和“重修”标记
- 从课表截图识别中文课程、教室并生成待确认课程
- 初次使用设置姓名、性别和 5 套莫兰迪主题
- 男生模式隐藏经期记录
- 每日心情、见解、经期开始日和整月心情视图
- 四季本地动态背景：春日花瓣、夏日海浪、秋日落叶、冬日飘雪
- 从手机一次导入多段风景视频，支持随机轮播或固定播放
- 全部个人数据保存在手机本地，可导出/恢复 JSON 备份

## 正式发布版本

菜单 **Build → Generate Signed Bundle / APK**，选择 APK，然后创建自己的 `.jks` 签名文件。签名文件和密码必须妥善保存；以后发布同一个应用的更新仍需使用同一把签名密钥。本项目不会附带任何密钥。

## 课表图片识别说明

项目使用随 APK 打包的 ML Kit 中文识别模型，识别过程可在本机完成。图片布局千差万别，因此导入后会先显示结果，务必检查星期、节次和教室；识别不准时可以点开课程手动修改。清晰、正面、只保留课表区域的截图效果最好。

## 自定义动态视频

进入 **设置 → 动态风景 → 导入自己的风景视频**，可多选海浪、森林、晚霞、雪景等本地视频。应用只保存系统授予的读取地址，不会复制或上传视频。若原视频后来被删除或移动，重新导入即可。

建议选择 10～30 秒、1080p 以内的小视频。超高分辨率或超长视频可能增加耗电，也可能在低端手机上卡顿。
